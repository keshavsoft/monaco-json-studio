A richer npm interface · the same generated studio

Describe panes with an object.

Use npm from JavaScript when a studio needs custom labels, files, controls, and starting data. The generator turns the object into the same static HTML, CSS, and browser-side Monaco project.

Local source preview: v7 is implemented in this checkout and has not been published. The existing npx command remains the pane-count command. The published package does not yet expose this named API.

One config object

Install the package after the v7 API is released, then import the named function:

import { createStudio } from 'monaco-json-studio';

createStudio({
  title: 'Dataset Review',
  outputDir: './dataset-review',
  panes: [
    {
      key: 'catalog',
      label: 'Catalog',
      header: {
        type: 'select',
        options: [
          { label: 'Fasteners', value: 'fasteners', content: [{ item: 'Bolt' }] },
          { label: 'Electrical', value: 'electrical', content: [{ item: 'Cable' }] }
        ]
      },
      body: { type: 'monaco', language: 'json' },
      footer: { type: 'note', text: 'Choose a dataset above.' }
    }
  ]
});

outputDir is relative to the process working directory and defaults to ./monaco-studio. A studio supports one, two, or three panes.

Choose a control for each region

Header

file-picker opens a local file, title shows the pane label, select switches the Monaco content between options, and none leaves the region empty.

Body

monaco creates an editor with the requested language and initial JSON value. The file name and initial value can be set in the body.

Footer

cursor displays the current position, note shows a short message, and none omits the pane footer.

A select header needs options with unique values and JSON content. Its first option is selected by default; set selectedValue to choose another.

Three runnable variations

The checkout includes a one-pane quick desk, a two-pane dataset review, and a three-pane data pipeline. The last two use the functional select control.

npm run demo:v7
npm run dev:v7

Then open the v7 examples index. The source examples are in examples/npm-v7/generate-variations.mjs.

Use logical keys, not hand-written DOM IDs

Each pane needs a unique key. The generator derives editor, file-picker, selector, and cursor IDs from the pane’s position. Browser behavior connects through the generated pane config, so the consumer does not repeat IDs in the object.

The public package root keeps the default count-based generator for the existing CLI and adds createStudio as a named npm API.
