One public entry point

Use the same pane count from Node.

The package root exposes one default generator. The HTML assemblers, region creators, and serializer remain internal implementation details.

Release status: v6 is local source work and has not been published. The import below documents the intended package interface after release. To try the current checkout, run node ./bin/index.js 3.

Install after release

npm install monaco-json-studio

Generate a studio

import generateStudio from 'monaco-json-studio';

generateStudio(3);

The only generator input is the pane count: 1, 2, or 3. The output is written to ./monaco-studio under the current working directory.

What stays behind the entry point

Internally, v6 uses Handlebars templates to create the global studio header and footer, the workspace grid, and each pane’s header, body, and footer. Those templates and functions can change without making consumers learn a larger API.

For the command-line version and generated directory structure, see the v6 command guide. For the internal module story, see how v6 builds the studio.
