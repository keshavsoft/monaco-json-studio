One public entry point

Use the same pane count from Node.

The package root exposes one default generator. The HTML assemblers, region creators, and serializer remain internal implementation details.

Release status: v5 is local source work and has not been published. The import below documents the intended package interface after release. To try the current checkout, run node ./bin/index.js 3.

Install after release

npm install monaco-json-studio

Generate a studio

import generateStudio from 'monaco-json-studio';

generateStudio(3);

The only generator input is the pane count: 1, 2, or 3. The output is written to ./monaco-studio under the current working directory.

What stays behind the entry point

Internally, v5 creates the global studio header and footer, creates the workspace grid, and assembles each pane from its own header, body, and footer. Those functions can change as the implementation improves without making consumers learn a larger API.

For the command-line version and generated directory structure, see the v5 command guide. For the internal module story, see how v5 builds the studio.
