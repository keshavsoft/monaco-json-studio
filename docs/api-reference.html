Node.js Module API

Programmatic API Reference

Integrate the studio generator, spec assembler, and HTML builder directly into your Node.js pipelines.

Installation

npm install @keshavsoft/monaco-json-studio

Importing Modules

import { 
  generateStudio, 
  buildHtml, 
  specToHtml, 
  assembleSpec 
} from "@keshavsoft/monaco-json-studio";

Functions

generateStudio(options)

Scaffolds the physical directory structure, copies assets, and writes pre-compiled HTML and JS controllers to disk.

Parameters: options (Object)

Property Type Default Description
inPanes number 2 Number of Monaco editor panes to generate (1, 2, or 3).
inTargetDir string './monaco-studio' Destination folder where physical files will be created.
inTitle string 'Monaco Studio' Title displayed in the generated application header bar.

Example:

import { generateStudio } from "@keshavsoft/monaco-json-studio";

const result = generateStudio({
  inPanes: 2,
  inTargetDir: "./dist/api-studio",
  inTitle: "Customer Data Inspector"
});

console.log(`Generated studio at: ${result.targetDir}`);

assembleSpec(options)

Builds the in-memory studio JSON specification object without writing to disk.

import { assembleSpec } from "@keshavsoft/monaco-json-studio";

const spec = assembleSpec({
  inPanes: 3,
  inTitle: "Pipeline Viewer"
});

console.log(spec.header.title); // "Pipeline Viewer"
console.log(spec.panes.length); // 3

specToHtml(spec)

Converts a studio specification object directly into clean semantic HTML body content.

import { assembleSpec, specToHtml } from "@keshavsoft/monaco-json-studio";

const spec = assembleSpec({ inPanes: 2 });
const bodyHtml = specToHtml(spec);
// Returns pre-rendered header, workspace panes, and footer elements

buildHtml(options)

Generates the complete index.html document string with full doctype, stylesheet links, and script tags.

import { buildHtml } from "@keshavsoft/monaco-json-studio";

const fullHtml = buildHtml({
  inPanes: 2,
  inTitle: "Microservice Schema Studio"
});
