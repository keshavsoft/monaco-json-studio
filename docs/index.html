Monaco JSON Studio · v6 source preview

Choose the pane count. Get the whole studio.

A single count generates the shell, the pane layout, and each pane’s header, Monaco body, and footer as a static HTML workspace.

Local source preview

v6 is implemented in this checkout and has not been published. The published npm package remains on its earlier release until a new release is made.

The Story & Philosophy

Modern web development often introduces heavyweight build chains, bundlers, and runtime dependencies just to display and inspect JSON files side-by-side in Monaco Editor. When inspecting configuration files, API responses, schema definitions, or translation tables, developers want instant physical static files without orchestrating servers, webpack, or Vite builds.

Monaco JSON Studio keeps the consumer choice small and organizes the generated page into focused internal parts:

🚀

One-Shot NPX Command

Run one command and specify the number of panes: 1, 2, or 3.

📄

100% Static HTML Output

No empty root mount containers. All DOM structures, headers, split panes, and controls are pre-compiled directly into index.html.

🎨

Modular Control-Scoped CSS

Separates page tokens, studio shell, pane grid, and pane-region styles into focused CSS files.

📂

Independent Pane Controls

Every editor pane has its own independent file picker, filename badge, and live JSON validator wired out of the box.

Quick NPX Example

# Instantly generate a 2-Pane Dual JSON Studio
npx monaco-json-studio 2

# Open the studio in your browser immediately (100% static)
cd monaco-studio
# Double-click index.html or serve locally:
npx serve .

Zero Runtime Assembler Overhead

The generated studio requires no server backend, no database, and no compilation step. It is completely portable and can be deployed instantly to GitHub Pages, Cloudflare Pages, S3, or any static host.
