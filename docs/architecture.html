Static Architecture & Specifications

How the declarative spec engine compiles into 100% static, physical project files.

Current v7 source story

This page describes the earlier spec-compiler architecture. The v7 named npm API accepts a pane object and composes the shell, workspace, and pane regions through focused functions and Handlebars templates. The count-only CLI remains available. Read the v7 npm API guide.

Directory Structure of Scaffolded Output

When you scaffold a project, the generator produces this clean, production-ready directory layout:

my-studio/
├── css/
│   ├── base.css          # Reset, theme tokens & typography
│   ├── header.css        # Branding, title & navigation bar styles
│   ├── workspace.css     # Flexbox layout, split panes & editors
│   └── footer.css        # Status bar & metadata layout
├── data/
│   ├── data.json         # Seed dataset 1
│   ├── instructions.json # Seed dataset 2 (if panes >= 2)
│   └── columns.json      # Seed dataset 3 (if panes >= 3)
├── js/
│   ├── state.js          # Reactive runtime state & utilities
│   └── index.js          # Monaco loader & pane wiring controller
└── index.html            # 100% pre-rendered static HTML markup

Spec-to-HTML Compilation Pipeline

The core pipeline follows a deterministic four-phase generation cycle:

1️⃣

assembleSpec

Combines header.spec.json, pane.spec.json, and footer.spec.json into an in-memory studio AST based on pane count.

2️⃣

specToHtml

Transforms the spec tree into clean, deterministic semantic HTML markup without empty template tags or placeholders.

3️⃣

buildHtml

Wraps the generated body markup with script imports, Google Fonts, and modular stylesheet links inside a complete HTML5 envelope.

4️⃣

generateStudio

Physically creates directories on disk, copies CSS/sample data assets, and writes out index.html and JS controllers.

Modular Control-Scoped CSS

Instead of a monolithic CSS bundle, monaco-json-studio isolates presentation concerns into four lightweight files:

Stylesheet Responsibility
css/base.css Global CSS variables, font families, dark theme colors (#1e1e1e, #252526), and box sizing.
css/header.css Top navigation layout, title styling, and header actions.
css/workspace.css Dynamic flex splits (100%, 50%, 33.33%), pane borders, headers, buttons, and Monaco container heights.
css/footer.css Fixed bottom status bar, item counters, and file-loaded notifications.

Zero Runtime Bundler Requirements

Offline and CDN Flexibility

The generated studio fetches Monaco Editor from CDN via standard RequireJS loader (configured for cdnjs.cloudflare.com/ajax/libs/monaco-editor/0.52.2/min/vs). No Webpack, Rollup, or Vite server required.
