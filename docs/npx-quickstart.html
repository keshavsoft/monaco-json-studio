NPX Quickstart & CLI Guide

Scaffold standalone, production-ready Monaco JSON Studio workspaces anywhere with a single terminal command.

Instant Scaffolding via NPX

You do not need to install the package globally. Run it directly with npx:

# Syntax:
npx @keshavsoft/monaco-json-studio <panes> [targetDir] [options]

Primary Arguments

Argument Type Description
<panes> 1 | 2 | 3 Required. The number of editor panes: 1 (single 100%), 2 (dual 50/50), or 3 (triple 33/33/33).
[targetDir] string Optional. Destination path (e.g., ./my-studio or . for current folder). Defaults to ./monaco-studio.

Supported CLI Flags & Options

Option Default Description
--title=<name> "Monaco Studio" Custom branding title rendered in the generated studio header bar.
--panes=<1|2|3> - Named argument variant for specifying pane count.
--target=<path> ./monaco-studio Named argument variant for specifying target directory.
-h, --help - Displays the CLI usage instructions and parameter table.

Scaffolding Examples

1. Single Pane JSON Visualizer

Generates a full-width Monaco editor suitable for viewing and formatting a single JSON document:

npx @keshavsoft/monaco-json-studio 1 ./single-viewer --title="Config Inspector"

2. Dual Pane Split View (50% / 50%)

Generates two side-by-side Monaco editors ideal for diffing API outputs or comparing schemas:

npx @keshavsoft/monaco-json-studio 2 ./dual-studio --title="API Response Diff"

3. Triple Pane Studio (33% / 33% / 33%)

Generates three side-by-side Monaco editors for complex multi-stage pipelines (e.g., Input Data, Columns Spec, Instructions):

npx @keshavsoft/monaco-json-studio 3 ./pipeline-studio --title="ETL Config Studio"

4. Scaffold Directly into Current Directory

npx @keshavsoft/monaco-json-studio 2 .

Running Locally from Source

If you have cloned or linked this repository locally:

# Inside the monaco-json-studio repository root:
node ./bin/index.js 2 ./my-dual-studio

# Test npm run script:
npm test

What Happens After Execution?

The CLI compiles the spec, creates physical folder structures, copies all modular CSS files, copies sample JSON datasets, and generates a pre-rendered index.html with the respective JavaScript controllers. Ready to use immediately!
