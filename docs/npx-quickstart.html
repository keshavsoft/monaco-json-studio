Monaco JSON Studio · v5

One command. Pick the pane count.

The consumer chooses the workspace size. The generator composes the headers, editor bodies, footers, HTML, and CSS.

Local source preview: v5 is in this repository and has not been published. The command below describes v5. The npm registry continues to serve the previously published release until a new version is released.

Command

Run the package from your project directory. It creates ./monaco-studio.

npx monaco-json-studio 3

Choose a layout

One pane

Full width

Use for one JSON document or a focused viewer.

npx monaco-json-studio 1
Two panes

Side by side

Use for instructions and data, or for comparing two documents.

npx monaco-json-studio 2
Three panes

Three stages

Use for instructions, input data, and an output view.

npx monaco-json-studio 3

Try the local checkout

From the cloned repository root, run the source directly:

node ./bin/index.js 3

The local generator writes the project to ./monaco-studio. Serve that folder with a static web server to load Monaco and the sample JSON files.

What is inside?

monaco-studio/
├── index.html
├── css/
│   ├── base.css
│   ├── studio.css
│   ├── pane-layout.css
│   └── pane-regions.css
├── data/
└── js/
    ├── index.js
    └── state.js

One public choice, clear internal parts

The pane count drives the workspace. Inside the generator, studio-level header and footer modules frame the page, while each pane is assembled from a pane header, body, and footer. The generated project stays plain HTML and CSS around the Monaco control.
