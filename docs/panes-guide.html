Multi-Pane Layouts (1, 2, or 3 Panes)

Learn how each pane mode is wired, structured, and customized for different data comparison scenarios.

Comparison Matrix

Pane Mode Width Distribution Best Suited For Sample Data Seeded
1 Pane 100% full width JSON data inspection, log examination, schema viewing data.json
2 Panes 50% / 50% split Before/After diffing, Input vs Output, Schema vs Mock data.json, instructions.json
3 Panes 33.33% each Data + Column Specs + Transformation Instructions data.json, instructions.json, columns.json

Detailed Pane Profiles

1. Single Pane (100% Full Width)

When you scaffold with 1, the workspace compiles a single full-width container:

<div class="workspace">
  <div class="pane" id="pane1" style="width: 100%;">
    <div class="pane-header">
      <span class="badge">Data</span>
      <span id="fileName1" class="file-name">data.json</span>
      <button id="fileBtn1" class="btn">Open File</button>
      <input type="file" id="fileInput1" accept=".json" hidden>
    </div>
    <div id="editor1" class="editor-container"></div>
  </div>
</div>

Use Case: Clean viewer for standalone JSON documents with formatting, folding, and search.

2. Dual Pane (50% / 50% Split)

The most popular split layout. Generates two balanced editors with distinct pane IDs (#pane1 and #pane2):

npx @keshavsoft/monaco-json-studio 2 ./my-dual-studio
  • Left Pane: Seeds with data.json
  • Right Pane: Seeds with instructions.json
  • Controls: Both panes maintain independent file upload buttons, formatters, and status updates.

3. Triple Pane (33% / 33% / 33% Split)

Built for advanced multi-layer workflows:

npx @keshavsoft/monaco-json-studio 3 ./my-triple-studio
  • Pane 1 (33.33%): Data Source (data.json)
  • Pane 2 (33.33%): Column Spec (instructions.json)
  • Pane 3 (33.33%): Transformation/Format Rules (columns.json)

Independent Pane Event Architecture

Each editor pane is initialized with its own event wiring:

  • Local File Reading: Selecting a .json file on Pane 2 updates only Pane 2's editor model and file badge without refreshing or resetting Pane 1.
  • Automatic Formatting: Loaded JSON files are run through a pretty-printer (JSON.stringify(JSON.parse(text), null, 2)) automatically.
  • State Isolation: The controller maintains state arrays state.editors[], state.fileNames[], and state.contents[] indexed by pane order.
