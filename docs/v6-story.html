Monaco JSON Studio · Version 6

One number enters. A studio comes out.

Choose one, two, or three panes. Handlebars turns focused HTML templates into the studio shell and pane regions. CSS arranges them into the static page.

1–3 panesOne public inputHandlebars at generation timeStatic generated page

The consumer command stays small

The count sets the number of panes and the corresponding workspace grid. The generator writes its output into ./monaco-studio.

npx monaco-json-studio 3
ℹ
Local preview: v6 is in this source checkout and has not been published. Try it here with node ./bin/index.js 3; the registry command will use the existing published release until a new release is made.

How the number becomes a page

Each phase has a focused function. The CLI does not need to know which region templates are used.

01 · Validate

Pane count

Accept only 1, 2, or 3.

02 · Frame

Studio shell

Create the global header and status footer.

03 · Arrange

Workspace

Select the matching CSS grid.

04 · Compose

Pane regions

Create each header, Monaco body, and footer.

05 · Emit

Static project

Write HTML and copy CSS, data, and runtime files.

Functions build the parts; templates show the markup

The region-creation functions select a Handlebars template and supply its data. Each template is readable HTML, so a maintainer can see what the control emits without inspecting an abstract HTML tree.

src/v6/
├── generateStudio/       public generation operation
├── createStudioDocument/ joins the studio shell and workspace
├── createStudioHeader/
├── createWorkspace/
├── createPane/           composes three pane regions
├── createPaneHeader/
├── createPaneBody/
├── createPaneFooter/
├── createStudioFooter/

assets/v6/templates/
├── document.hbs
├── studio-header.hbs
├── workspace.hbs
├── pane.hbs
└── regions/
    ├── header/           file-picker.hbs, title.hbs
    ├── body/             monaco.hbs
    └── footer/           cursor.hbs, note.hbs

Handlebars is only used by the Node generator. The output page is plain HTML and CSS; it does not load Handlebars.

Vite serves the local preview

Vite is a development dependency for iterating on the generated page. It is separate from both the count-only CLI contract and the generated runtime.

cd preview-v6
node ../bin/index.js 3
cd ..
npm run dev:v6

The Vite server opens the generated preview under preview-v6/monaco-studio. The generated project itself can still be served by any static host.

Readable source, straightforward usage

The user picks a count. The source stays organized around recognizable page parts. Handlebars handles repeated markup, and the browser receives the same simple static project.
